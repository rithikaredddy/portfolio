Online Judge Platform

React 18, Monaco Editor, Node.js, Express, MongoDB, Docker, JWT

A small LeetCode-style site. You sign up, pick a problem, write a solution in Python, C++ or Java in the browser, and get a verdict: Accepted, Wrong Answer, Time Limit Exceeded or Runtime Error.

The interesting part is the backend. Running code that strangers type into a text box is risky, so every submission runs in its own Docker container built for that language, with a time limit. The output is checked against hidden test cases, and the result is saved so it shows up in your history, your solved count and the global leaderboard.

Movie Recommendation Engine

Next.js 14, Tailwind CSS, FastAPI, MongoDB (Motor), scikit-learn, Surprise, JWT

A movie site that learns what you like. You search, open a movie and rate it from one to five stars, and the recommendations on your profile change as you rate more.

It combines two approaches. Content-based filtering (TF-IDF on genre, cast and keywords, compared with cosine similarity) answers "more like this movie". Collaborative filtering (SVD matrix factorization) answers "people who rate like you also liked". The default feed is a weighted blend of both. The models are trained on the MovieLens 100K dataset: 100,000 ratings from 943 users on 1,682 movies.

How a recommendation is built
